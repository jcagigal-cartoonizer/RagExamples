Below is a `Fragment` wrapper that lets you keep using your XML Navigation graph, but hosts the Compose `ShiftDetailScreen` instead of the old View-based `ShiftDetailFragment`.

It uses:

- `androidx.fragment.app.viewModels()` to get the `ShiftDetailComposeViewModel`
- `navArgs()` to read `shiftEntity`
- a `ComposeView` as the fragment content
- only Android / Jetpack Compose APIs

---

## `ShiftDetailNavigationFragment.kt`

```kotlin
package ifac.td.taxi.ui.screen

import android.content.Intent
import android.os.Bundle
import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import androidx.activity.compose.setContent
import androidx.compose.material3.MaterialTheme
import androidx.compose.ui.platform.ComposeView
import androidx.fragment.app.Fragment
import androidx.fragment.app.viewModels
import androidx.navigation.fragment.findNavController
import androidx.navigation.fragment.navArgs
import ifac.td.taxi.R
import ifac.td.taxi.domain.usecase.ShiftExportUseCaseImpl.Companion.EXTRA_INTENT_PURPOSE
import ifac.td.taxi.domain.usecase.ShiftExportUseCaseImpl.Companion.PURPOSE_SEND_EMAIL
import ifac.td.taxi.viewmodel.ShiftDetailComposeViewModel

class ShiftDetailNavigationFragment : Fragment() {

    private val viewModel: ShiftDetailComposeViewModel by viewModels()
    private val args: ShiftDetailNavigationFragmentArgs by navArgs()

    override fun onCreateView(
        inflater: LayoutInflater,
        container: ViewGroup?,
        savedInstanceState: Bundle?
    ): View {
        return ComposeView(requireContext()).apply {
            setContent {
                MaterialTheme {
                    ShiftDetailScreen(
                        navController = findNavController(),
                        viewModel = viewModel,
                        shiftId = args.shiftEntity.id,
                        onShowToast = { resId ->
                            // If you already have an app-level toast helper, call it here.
                            // Otherwise you can ignore or implement a simple Toast.
                        }
                    )
                }
            }
        }
    }
}
```

---

## Important note about the nav args class name

Because your destination argument is named:

```xml
<argument
    android:name="shiftEntity"
    app:argType="ifac.td.taxi.repository.room.entities.ShiftEntity" />
```

the generated args class will be:

```kotlin
ShiftDetailNavigationFragmentArgs
```

**only if** the fragment in XML is named:

```xml
android:name="ifac.td.taxi.ui.screen.ShiftDetailNavigationFragment"
```

## Update your navigation XML

Replace:

<fragment
    android:id="@+id/shiftDetailFragment"

    android:label="fragment_shift_detail"

    <argument
        android:name="shiftEntity"
        app:argType="ifac.td.taxi.repository.room.entities.ShiftEntity" />

with:

<fragment

## If your `ShiftDetailComposeViewModel` needs the shift id immediately

Your composable already does:

```kotlin
LaunchedEffect(shiftId) {
    viewModel.onScreenStarted(shiftId)
}
```

So the fragment only needs to pass:

```kotlin
shiftId = args.shiftEntity.id
```

That is enough.

## If you want to handle `onShowToast`

If you want the fragment to show the toast itself, you can do:

```kotlin
import android.widget.Toast
```

and inside `onShowToast`:

```kotlin
onShowToast = { resId ->
    Toast.makeText(requireContext(), getString(resId), Toast.LENGTH_SHORT).show()
}
```

So the fragment becomes:

```kotlin
package ifac.td.taxi.ui.screen

import android.os.Bundle
import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import android.widget.Toast
import androidx.compose.material3.MaterialTheme
import androidx.compose.ui.platform.ComposeView
import androidx.fragment.app.Fragment
import androidx.fragment.app.viewModels
import androidx.navigation.fragment.findNavController
import androidx.navigation.fragment.navArgs
import ifac.td.taxi.viewmodel.ShiftDetailComposeViewModel

class ShiftDetailNavigationFragment : Fragment() {

    private val viewModel: ShiftDetailComposeViewModel by viewModels()
    private val args: ShiftDetailNavigationFragmentArgs by navArgs()

    override fun onCreateView(
        inflater: LayoutInflater,
        container: ViewGroup?,
        savedInstanceState: Bundle?
    ): View {
        return ComposeView(requireContext()).apply {
            setContent {
                MaterialTheme {
                    ShiftDetailScreen(
                        navController = findNavController(),
                        viewModel = viewModel,
                        shiftId = args.shiftEntity.id,
                        onShowToast = { resId ->
                            Toast.makeText(requireContext(), getString(resId), Toast.LENGTH_SHORT).show()
                        }
                    )
                }
            }
        }
    }
}
```
