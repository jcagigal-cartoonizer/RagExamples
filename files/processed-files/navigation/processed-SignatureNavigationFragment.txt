## Notes
### 1) If your `SignatureComposeViewModel` is actually in another package
Your sample shows:
```kotlin
// # Block 74-2: import ifac.td.taxi.compose.viewmodel.*
import ifac.td.taxi.compose.viewmodel.*
```
So keep the import consistent with your project structure. If the actual class is in a different package, adjust:
```kotlin
private val viewModel: SignatureComposeViewModel by viewModels()
```
accordingly.
### 2) About `onShowHeader` and `onShowToast`
Your composable requires callbacks, but your old fragment used:
In this fragment wrapper, I left placeholders because you requested only Android + Compose references. If your activity exposes those methods, you can wire them like this:
```kotlin
onShowHeader = { show ->
    (activity as? MainActivity)?.showHeader(show)
}
onShowToast = { resId ->
    Toast.makeText(requireContext(), resId, Toast.LENGTH_SHORT).show()
}
```
