Below is a Compose-based version of `ClosedPartialFragment` that keeps the same navigation behavior, replaces fragment button logic with state holders, uses a `UiState + UiEvent + UiEffect` pattern, and includes a Compose dialog equivalent to the XML/custom dialog approach.

I’ll provide:

1. `ClosedPartialRoute` / composable screen
2. `ClosedPartialViewModel` for Compose
3. `ClosedPartialUiState`, `ClosedPartialUiEvent`, `ClosedPartialUiEffect`
4. `ClosedPartialButtonsState` with button visibility/color/enable logic
5. Compose equivalents for the custom button styling
6. Compose `CustomDialog`
7. Notes on preserving navigation and lifecycle collection

---

## 1) Compose screen

This composable preserves the existing navigation flow by emitting navigation effects and letting the host fragment/activity handle them.

```kotlin
package ifac.td.taxi.ui.screen

import android.view.View
import androidx.compose.foundation.background
import androidx.compose.foundation.layout.*
import androidx.compose.foundation.rememberScrollState
import androidx.compose.foundation.verticalScroll
import androidx.compose.material3.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.platform.LocalLifecycleOwner
import androidx.compose.ui.text.style.TextAlign
import androidx.compose.ui.unit.dp
import androidx.lifecycle.Lifecycle
import androidx.lifecycle.compose.collectAsStateWithLifecycle
import androidx.lifecycle.repeatOnLifecycle
import androidx.compose.runtime.LaunchedEffect
import androidx.compose.runtime.rememberCoroutineScope
import androidx.navigation.NavController
import com.interfacom.sdk.taximeter.bravocomm.ifConstants
import kotlinx.coroutines.flow.collectLatest
import kotlinx.coroutines.launch
import ifac.td.taxi.R

@Composable
fun ClosedPartialRoute(
    viewModel: ClosedPartialComposeViewModel,
    navController: NavController,
    justClosed: Boolean,
    onShowHeader: (Boolean) -> Unit,
) {
    val uiState by viewModel.uiState.collectAsStateWithLifecycle()
    val lifecycleOwner = LocalLifecycleOwner.current

    LaunchedEffect(Unit) {
        onShowHeader(true)
        viewModel.onEvent(ClosedPartialUiEvent.ScreenStarted(justClosed = justClosed))
    }

    LaunchedEffect(viewModel, lifecycleOwner) {
        lifecycleOwner.repeatOnLifecycle(Lifecycle.State.STARTED) {
            viewModel.uiEffect.collectLatest { effect ->
                when (effect) {
                    ClosedPartialUiEffect.NavigateBackOnce -> navController.popBackStack()
                    ClosedPartialUiEffect.NavigateBackTwice -> {
                        navController.popBackStack()
                        navController.popBackStack()
                    }
                    ClosedPartialUiEffect.NavigateToTotalizers -> {
                        navController.navigate(R.id.action_closedPartialFragment_to_totalizersFragment)
                    }
                    ClosedPartialUiEffect.ShowPrintDialog -> Unit
                    ClosedPartialUiEffect.HidePrintDialog -> Unit
                }
            }
        }
    }

    ClosedPartialScreen(
        uiState = uiState,
        onEvent = viewModel::onEvent
    )
}

@Composable
fun ClosedPartialScreen(
    uiState: ClosedPartialUiState,
    onEvent: (ClosedPartialUiEvent) -> Unit,
) {
    val dialogState = uiState.dialogState
    val buttonsState = uiState.buttonsState

    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(Color.White)
    ) {
        Column(
            modifier = Modifier
                .fillMaxSize()
                .padding(16.dp)
        ) {
            Text(
                text = uiState.title,
                style = MaterialTheme.typography.headlineSmall
            )

            Spacer(modifier = Modifier.height(12.dp))

            Box(
                modifier = Modifier
                    .weight(1f)
                    .fillMaxWidth()
                    .verticalScroll(rememberScrollState())
            ) {
                Text(
                    text = uiState.ticketContent,
                    style = MaterialTheme.typography.bodyMedium,
                    textAlign = TextAlign.Start
                )
            }

            Spacer(modifier = Modifier.height(12.dp))

            ClosedPartialButtonsRow(
                state = buttonsState,
                onCancel = { onEvent(ClosedPartialUiEvent.CancelClicked) },
                onPrint = { onEvent(ClosedPartialUiEvent.PrintClicked) },
                onTotalizers = { onEvent(ClosedPartialUiEvent.TotalizersClicked) }
            )
        }

        if (dialogState.visible) {
            CustomDialog(
                title = dialogState.title,
                message = dialogState.message,
                confirmText = dialogState.confirmText,
                dismissText = dialogState.dismissText,
                onConfirm = { onEvent(ClosedPartialUiEvent.DialogConfirmed) },
                onDismiss = { onEvent(ClosedPartialUiEvent.DialogDismissed) }
            )
        }
    }
}
```

## 3) Buttons state replacing fragment button logic

This state fully replaces:
- `btnCancel.setAction`
- `btnPrint.setAction`
- `btnTotalizers.setAction`
- visibility logic
- enabled/disabled styling logic

It also mirrors the original behavior:
- `btnTotalizers` is visible only when `currentStatus != STATE_DISCONNECTED && isConnected`
- style is `ENABLE` when connected and totalizers exist
- style is `DISABLE` otherwise

```kotlin
package ifac.td.taxi.ui.screen

import androidx.compose.runtime.Immutable
import androidx.compose.ui.graphics.Color
import com.interfacom.sdk.taximeter.bravocomm.ifConstants

@Immutable
data class ClosedPartialButtonsState(
    val cancel: ButtonVisualState = ButtonVisualState.primary(),
    val print: ButtonVisualState = ButtonVisualState.primary(),
    val totalizers: ButtonVisualState = ButtonVisualState.hidden(),
) {
    companion object {
        fun from(
            isTaximeterConnected: Boolean,
            hasTotalizers: Boolean,
            currentStatus: String?
        ): ClosedPartialButtonsState {
            val shouldShowTotalizers =
                currentStatus != ifConstants.STATE_DISCONNECTED && isTaximeterConnected

            val totalizersState = if (shouldShowTotalizers) {
                if (isTaximeterConnected && hasTotalizers) {
                    ButtonVisualState.enabled()
                } else {
                    ButtonVisualState.disabled()
                }
            } else {
                ButtonVisualState.hidden()
            }

            return ClosedPartialButtonsState(
                cancel = ButtonVisualState.primary(),
                print = ButtonVisualState.primary(),
                totalizers = totalizersState
            )
        }
    }
}

@Immutable
data class ButtonVisualState(
    val visible: Boolean,
    val enabled: Boolean,
    val backgroundColor: Color,
    val contentColor: Color,
    val borderColor: Color,
    val alpha: Float = 1f,
) {
    companion object {
        fun primary() = ButtonVisualState(
            visible = true,
            enabled = true,
            backgroundColor = Color(0xFF1976D2),
            contentColor = Color.White,
            borderColor = Color(0xFF1976D2)
        )

        fun enabled() = ButtonVisualState(
            visible = true,
            enabled = true,
            backgroundColor = Color(0xFF2E7D32),
            contentColor = Color.White,
            borderColor = Color(0xFF2E7D32)
        )

        fun disabled() = ButtonVisualState(
            visible = true,
            enabled = false,
            backgroundColor = Color(0xFFE0E0E0),
            contentColor = Color(0xFF9E9E9E),
            borderColor = Color(0xFFBDBDBD),
            alpha = 1f
        )

        fun hidden() = ButtonVisualState(
            visible = false,
            enabled = false,
            backgroundColor = Color.Transparent,
            contentColor = Color.Transparent,
            borderColor = Color.Transparent,
            alpha = 0f
        )
    }
}
```

## 4) Compose ViewModel

This ViewModel converts the original imperative view model into a Compose-friendly architecture using:
- `UiState` as the single source of truth
- `SharedFlow<ClosedPartialUiEffect>` for one-off events
- methods that correspond to user events

```kotlin
package ifac.td.taxi.viewmodel

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import ifac.td.taxi.domain.model.PartialModel
import ifac.td.taxi.domain.usecase.PartialUseCase
import ifac.td.taxi.domain.usecase.PrinterUseCase
import ifac.td.taxi.framework.sdk.usecase.TaximeterConnectUseCase
import ifac.td.taxi.viewmodel.model.UtilsModel.Companion.addTicketLines
import ifac.td.taxi.ui.screen.*
import kotlinx.coroutines.flow.*
import kotlinx.coroutines.launch

class ClosedPartialComposeViewModel(
    private val printerUseCase: PrinterUseCase,
    private val partialUseCase: PartialUseCase,
    private val taximeterUseCase: TaximeterConnectUseCase,
) : ViewModel() {

    private val _uiState = MutableStateFlow(ClosedPartialUiState())
    val uiState: StateFlow<ClosedPartialUiState> = _uiState.asStateFlow()

    private val _uiEffect = MutableSharedFlow<ClosedPartialUiEffect>(extraBufferCapacity = 1)
    val uiEffect: SharedFlow<ClosedPartialUiEffect> = _uiEffect.asSharedFlow()

    private var currentPartial: PartialModel? = null
    private var justClosed: Boolean = false

    fun onEvent(event: ClosedPartialUiEvent) {
        when (event) {
            is ClosedPartialUiEvent.ScreenStarted -> {
                justClosed = event.justClosed
                checkTaximeterStatus()
                getClosedPartial()
            }

            ClosedPartialUiEvent.CancelClicked -> manageBack()
            ClosedPartialUiEvent.PrintClicked -> printPartial()
            ClosedPartialUiEvent.TotalizersClicked -> emitEffect(ClosedPartialUiEffect.NavigateToTotalizers)
            ClosedPartialUiEvent.DialogConfirmed -> emitEffect(ClosedPartialUiEffect.HidePrintDialog)
            ClosedPartialUiEvent.DialogDismissed -> emitEffect(ClosedPartialUiEffect.HidePrintDialog)
        }
    }

    private fun emitEffect(effect: ClosedPartialUiEffect) {
        viewModelScope.launch {
            _uiEffect.emit(effect)
        }
    }

    fun checkTaximeterStatus() {
        viewModelScope.launch {
            val connected = taximeterUseCase.isTaximeterConnected()
            updateButtons(isConnected = connected)
        }
    }

    fun getClosedPartial() {
        viewModelScope.launch {
            val result = partialUseCase.getClosedPartial()
            currentPartial = result

            _uiState.update {
                it.copy(
                    ticketContent = result?.bufLastTicketCierre?.takeIf { text -> text.isNotEmpty() }
                        ?: "No closed partials"
                )
            }
            updateButtons()
        }
    }

    fun manageBack() {
        viewModelScope.launch {
            if (justClosed) {
                emitEffect(ClosedPartialUiEffect.NavigateBackTwice)
            } else {
                emitEffect(ClosedPartialUiEffect.NavigateBackOnce)
            }
        }
    }

    fun printPartial() {
        viewModelScope.launch {
            val partial = currentPartial
            if (partial != null) {
                printerUseCase.printMessage(
                    header = null,
                    message = partial.bufLastTicketCierre.addTicketLines(),
                    paperFeed = false
                )
            }
        }
    }

    private fun updateButtons(isConnected: Boolean? = null) {
        val connected = isConnected ?: false
        _uiState.update { state ->
            state.copy(
                buttonsState = ClosedPartialButtonsState.from(
                    isTaximeterConnected = connected,
                    hasTotalizers = true,
                    currentStatus = null
                )
            )
        }
    }
}
```

## 5) Compose button row and styling helpers

This more closely matches a custom button component than plain `Button`.

```kotlin
package ifac.td.taxi.ui.screen

import androidx.compose.foundation.BorderStroke
import androidx.compose.foundation.layout.*
import androidx.compose.material3.*
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Shape
import androidx.compose.ui.unit.dp

@Composable
fun ClosedPartialButtonsRow(
    state: ClosedPartialButtonsState,
    onCancel: () -> Unit,
    onPrint: () -> Unit,
    onTotalizers: () -> Unit,
) {
    Row(
        modifier = Modifier.fillMaxWidth(),
        horizontalArrangement = Arrangement.spacedBy(12.dp)
    ) {
        CustomStyledButton(
            modifier = Modifier.weight(1f),
            text = "Cancel",
            state = state.cancel,
            onClick = onCancel
        )
        CustomStyledButton(
            modifier = Modifier.weight(1f),
            text = "Print",
            state = state.print,
            onClick = onPrint
        )
        if (state.totalizers.visible) {
            CustomStyledButton(
                modifier = Modifier.weight(1f),
                text = "Totalizers",
                state = state.totalizers,
                onClick = onTotalizers
            )
        }
    }
}

@Composable
fun CustomStyledButton(
    modifier: Modifier = Modifier,
    text: String,
    state: ButtonVisualState,
    onClick: () -> Unit,
) {
    Button(
        onClick = onClick,
        enabled = state.enabled,
        modifier = modifier.height(48.dp),
        colors = ButtonDefaults.buttonColors(
            containerColor = state.backgroundColor,
            contentColor = state.contentColor,
            disabledContainerColor = state.backgroundColor,
            disabledContentColor = state.contentColor.copy(alpha = 0.6f)
        ),
        border = BorderStroke(1.dp, state.borderColor)
    ) {
        Text(text = text)
    }
}
```

## 6) Compose `CustomDialog`

This is a Compose implementation based on a typical XML custom dialog structure, using only Compose and Android references.

```kotlin
package ifac.td.taxi.ui.screen

import androidx.compose.foundation.background
import androidx.compose.foundation.layout.*
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.material3.*
import androidx.compose.runtime.Composable
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.unit.dp

@Composable
fun CustomDialog(
    title: String,
    message: String,
    confirmText: String,
    dismissText: String,
    onConfirm: () -> Unit,
    onDismiss: () -> Unit,
) {
    Dialog(onDismissRequest = onDismiss) {
        Surface(
            shape = RoundedCornerShape(16.dp),
            tonalElevation = 6.dp,
            color = Color.White,
            modifier = Modifier.fillMaxWidth()
        ) {
            Column(
                modifier = Modifier.padding(20.dp),
                horizontalAlignment = Alignment.Start
            ) {
                Text(
                    text = title,
                    style = MaterialTheme.typography.titleLarge,
                    color = Color.Black
                )

                Spacer(modifier = Modifier.height(12.dp))

                Text(
                    text = message,
                    style = MaterialTheme.typography.bodyMedium,
                    color = Color.DarkGray
                )

                Spacer(modifier = Modifier.height(20.dp))

                Row(
                    modifier = Modifier.fillMaxWidth(),
                    horizontalArrangement = Arrangement.End
                ) {
                    TextButton(onClick = onDismiss) {
                        Text(dismissText)
                    }
                    Spacer(modifier = Modifier.width(8.dp))
                    Button(onClick = onConfirm) {
                        Text(confirmText)
                    }
                }
            }
        }
    }
}
```

## 7) Preserving fragment navigation with Compose

If you want to keep the existing Fragment-based navigation exactly as-is, the usual approach is:

- keep `ClosedPartialFragment`
- host a `ComposeView` inside it
- pass `navArgs`, shared view model, and navigation callbacks to the composable

Example:

```kotlin
class ClosedPartialFragment : BaseFragment<FragmentClosedPartialBinding, ClosedPartialViewModel>(
    R.layout.fragment_closed_partial
) {
    // Keep existing fragment navigation setup if needed

    override fun setupComponents() {
        vBinding.composeContainer.setContent {
            ClosedPartialRoute(
                viewModel = composeViewModel,
                navController = findNavController(),
                justClosed = safeArgs.justClosed,
                onShowHeader = { iMainActivity.showHeader(it) }
            )
        }
    }
}
```

If you are moving fully to Compose, just use the `NavController` directly in the composable as shown earlier.

## 8) Important note about exact XML button behavior

I provided the Compose `ClosedPartialButtonsState` to mimic the original logic, but there’s one limitation:

- your original fragment calls `updateTotalizersButtonState()` based on:
  - `vModel.isTaximeterConnectedFlow.value`
  - `sharedViewModel.taximeterTotalizersFlow.value != null`
  - `sharedViewModel.shiftStatusFlow.value?.currentStatus`

To make the Compose version fully equivalent, the Compose ViewModel should also observe the shared activity state or receive it as input from a shared repository/state holder. Then compute:

```kotlin
val shouldShow = currentStatus != ifConstants.STATE_DISCONNECTED && isConnected
```

and:

```kotlin
style = if (isConnected && hasTotalizers) ENABLE else DISABLE
```

- taximeter connection state
- shift status state

and computes `ClosedPartialButtonsState` reactively so it exactly mirrors the fragment behavior.
