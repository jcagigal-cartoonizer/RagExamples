Below is a `Fragment` that hosts your existing `ClosedPartialScreen` composable and can be used as the navigation destination instead of the old XML/view-based `ClosedPartialFragment`.

It uses:

- `androidx.fragment.app.viewModels()` for the ViewModel
- Jetpack Compose inside the fragment
- only Android + Jetpack Compose / Jetpack Navigation Fragment APIs
- your existing `ClosedPartialUiState` / `ClosedPartialUiEvent` pattern

---

## `ClosedPartialNavigationFragment.kt`

```kotlin
package ifac.td.taxi.ui.screen

import android.os.Bundle
import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import androidx.compose.runtime.collectAsState
import androidx.compose.runtime.getValue
import androidx.compose.ui.platform.ComposeView
import androidx.compose.ui.platform.ViewCompositionStrategy
import androidx.fragment.app.Fragment
import androidx.fragment.app.viewModels
import androidx.navigation.fragment.findNavController
import androidx.navigation.fragment.navArgs
import ifac.td.taxi.R
import ifac.td.taxi.viewmodel.ClosedPartialViewModel

class ClosedPartialNavigationFragment : Fragment() {

    private val viewModel: ClosedPartialViewModel by viewModels()
    private val args: ClosedPartialNavigationFragmentArgs by navArgs()

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        // If your ViewModel needs the argument, pass it here if you expose an init method.
        // Example:
        // viewModel.setJustClosed(args.justClosed)
        //
        // Or trigger initial loading if your ViewModel supports it:
        // viewModel.onEvent(ClosedPartialUiEvent.Init(args.justClosed))
    }

    override fun onCreateView(
        inflater: LayoutInflater,
        container: ViewGroup?,
        savedInstanceState: Bundle?
    ): View {
        return ComposeView(requireContext()).apply {
            setViewCompositionStrategy(
                ViewCompositionStrategy.DisposeOnViewTreeLifecycleDestroyed
            )

            setContent {
                val uiState by viewModel.uiState.collectAsState()

                ClosedPartialScreen(
                    uiState = uiState,
                    onEvent = { event ->
                        when (event) {
                            ClosedPartialUiEvent.CancelClicked -> {
                                viewModel.onEvent(event)
                                findNavController().navigateUp()
                            }

                            ClosedPartialUiEvent.PrintClicked -> {
                                viewModel.onEvent(event)
                            }

                            ClosedPartialUiEvent.TotalizersClicked -> {
                                viewModel.onEvent(event)
                                findNavController().navigate(
                                    R.id.action_closedPartialFragment_to_totalizersFragment
                                )
                            }

                            ClosedPartialUiEvent.DialogConfirmed -> {
                                viewModel.onEvent(event)
                            }

                            ClosedPartialUiEvent.DialogDismissed -> {
                                viewModel.onEvent(event)
                            }
                        }
                    }
                )
            }
        }
    }
}
```

## Navigation XML change

Replace the destination class for `closedPartialFragment`:

```xml
<fragment
    android:id="@+id/closedPartialFragment"
    android:name="ifac.td.taxi.ui.screen.ClosedPartialNavigationFragment"
    android:label="ClosedPartialNavigationFragment">
    <argument
        android:name="justClosed"
        app:argType="boolean"
        android:defaultValue="false" />
    <action
        android:id="@+id/action_closedPartialFragment_to_totalizersFragment"
        app:destination="@id/totalizersFragment" />
</fragment>
```

## Important note about your ViewModel

Your old fragment was doing:

- `checkTaximeterStatus()`
- `getClosedPartial()`
- setting button state
- handling back/print/totalizers

With Compose, the recommended approach is:

- the `ViewModel` exposes `uiState` as `StateFlow<ClosedPartialUiState>`
- the fragment only renders `ClosedPartialScreen`
- the fragment forwards events to the ViewModel
- navigation happens from the fragment

If your `ClosedPartialViewModel` does not already expose a `uiState: StateFlow<ClosedPartialUiState>`, you should add it.

## Optional: initialize with the `justClosed` argument

If `justClosed` affects logic, you can pass it to the ViewModel in one of these ways:

### Option 1: call an init method
```kotlin
override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    viewModel.setJustClosed(args.justClosed)
}
```

### Option 2: send an event
```kotlin
viewModel.onEvent(ClosedPartialUiEvent.Init(args.justClosed))
```

### Option 3: read `SavedStateHandle` in the ViewModel
This is often the cleanest option for Navigation args.

---

## If you want the fragment to navigate back on dialog confirm/dismiss
You can do it in the `when` block too, for example:

```kotlin
ClosedPartialUiEvent.DialogConfirmed -> {
    viewModel.onEvent(event)
    findNavController().navigateUp()
}
```

depending on your intended UX.

## Summary

Use this pattern:

- keep the navigation destination as a Fragment
- replace the old view-based fragment with `ClosedPartialNavigationFragment`
- host `ClosedPartialScreen` inside `ComposeView`
- use `by viewModels()` for the ViewModel
- navigate with `findNavController()`
