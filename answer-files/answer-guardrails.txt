QUESTION
Give me a complete LangChain4j Java example of RAG (Retrieval-Augmented Generation) using guardrails to instruct the Ai model to only access some enterprise resources and not searching the Internet or not accessing remote sites that require authentication


ANSWER
Below is a **complete LangChain4j Java example** of a **RAG (Retrieval-Augmented Generation)** setup with **guardrails** that:

1. **Only retrieves from approved enterprise resources**
2. **Does not search the Internet**
3. **Does not access remote sites requiring authentication**
4. **Rejects or filters unsafe retrieval requests**
5. **Instructs the model to answer only from retrieved enterprise context**

> Important note:  
> In practice, the **model itself cannot be trusted to “not browse”** unless you **control the tools/retrievers** it can use.  
> So the real guardrail is:
> - **No web-search tool**
> - **Only a whitelisted document store / enterprise sources**
> - **Pre-filtering of URLs / sources**
> - **Prompt instructions**
> - **Answer-time refusal if context is insufficient**

  - unsupported sources

    public interface EnterpriseAssistant {
        String ask(String question);
    }

    // -----------------------------
    // Enterprise document model
    // -----------------------------
    public static class EnterpriseDocument {
        private final String id;
        private final String source;
        private final String text;

        public EnterpriseDocument(String id, String source, String text) {
            this.id = id;
            this.source = source;
            this.text = text;
        }

        public String id() { return id; }
        public String source() { return source; }
        public String text() { return text; }
    }

    // -----------------------------
    // Retriever with source whitelist
    // -----------------------------
    public static class WhitelistedEnterpriseContentRetriever implements ContentRetriever {

        private final List<EnterpriseDocument> documents;
        private final Set<String> allowedSourcePrefixes;

        public WhitelistedEnterpriseContentRetriever(List<EnterpriseDocument> documents,
                                                     Set<String> allowedSourcePrefixes) {
            this.documents = documents;
            this.allowedSourcePrefixes = allowedSourcePrefixes;
        }

        @Override
        public List<Content> retrieve(Query query) {
            String q = query.text().toLowerCase(Locale.ROOT);

            // Very simple keyword matching for demo purposes.
            // In production, use embeddings + vector store + metadata filters.
            List<EnterpriseDocument> matched = documents.stream()
                    .filter(doc -> isAllowedSource(doc.source()))
                    .filter(doc -> matchesQuery(doc.text(), q))
                    .toList();

            return matched.stream()
                    .map(doc -> Content.from(
                            TextSegment.from(doc.text()),
                            Map.of(
                                    "source", doc.source(),
                                    "documentId", doc.id()
                            )
                    ))
                    .collect(Collectors.toList());
        }

        private boolean isAllowedSource(String source) {
            return allowedSourcePrefixes.stream().anyMatch(source::startsWith);
        }

        private boolean matchesQuery(String text, String query) {
            String t = text.toLowerCase(Locale.ROOT);

            // crude but clear demo matching
            for (String token : query.split("\\s+")) {
                if (token.length() > 3 && t.contains(token)) {
                    return true;
                }
            }
            return false;
        }
    }

    // -----------------------------
    // Input guardrail
    // -----------------------------
    public static class EnterpriseInputGuardrail implements InputGuardrail {

        @Override
        public GuardrailResult validate(String userMessage) {
            String msg = userMessage.toLowerCase(Locale.ROOT);

            // Block explicit web/internet requests
            if (msg.contains("internet") || msg.contains("web search") || msg.contains("google")
                    || msg.contains("browse") || msg.contains("search the web")) {
                return GuardrailResult.fail("Internet/web access is not allowed. Use approved enterprise resources only.");
            }

            // Block URLs
            if (containsUrl(userMessage)) {
                return GuardrailResult.fail("External URLs are not allowed. Use approved enterprise resources only.");
            }

            // Block requests for authenticated remote sites
            if (msg.contains("login") || msg.contains("sign in") || msg.contains("authenticated")
                    || msg.contains("credentials") || msg.contains("password protected")) {
                return GuardrailResult.fail("Access to authenticated remote sites is not allowed.");
            }

            return GuardrailResult.pass();
        }

        private boolean containsUrl(String text) {
            return text.contains("http://") || text.contains("https://") || text.contains("www.");
        }
    }

    // -----------------------------
    // Output guardrail
    // -----------------------------
    public static class EnterpriseOutputGuardrail implements OutputGuardrail {

        @Override
        public GuardrailResult validate(String modelOutput) {
            // Optional: block model from claiming it accessed the web
            String out = modelOutput.toLowerCase(Locale.ROOT);

            if (out.contains("i searched the internet") || out.contains("i browsed")
                    || out.contains("i accessed the website")) {
                return GuardrailResult.fail("Model output suggests unauthorized web access.");
            }

            return GuardrailResult.pass();
        }
    }
}

# 4) Important correction: the imports above

The example above shows the **architecture**, but some of the guardrail imports in LangChain4j may differ depending on the exact version you use.

So here is the **practical version**:

- Use **AiServices**
- Use **ContentRetriever**
- Use **custom input validation before calling the assistant**
- Use **system prompt**
- Use **whitelisted retriever**
- Optionally add **output validation**

Because LangChain4j APIs evolve, the safest production pattern is:

- **Do not rely on a “browser tool”**
- **Do not register any tool that can access the Internet**
- **Only provide a retriever backed by approved enterprise data**
- **Reject user prompts that request web access**

# 5) Cleaner production-style version

If you want a more realistic and maintainable implementation, use this structure:

## A. Input validation before calling the assistant

```java
public class RequestPolicy {

    public static void validate(String question) {
        String q = question.toLowerCase(Locale.ROOT);

        if (q.contains("internet") || q.contains("google") || q.contains("browse") || q.contains("search the web")) {
            throw new IllegalArgumentException("Internet access is not allowed.");
        }

        if (q.contains("http://") || q.contains("https://") || q.contains("www.")) {
            throw new IllegalArgumentException("External URLs are not allowed.");
        }

        if (q.contains("login") || q.contains("authenticated") || q.contains("credentials")) {
            throw new IllegalArgumentException("Authenticated remote access is not allowed.");
        }
    }
}
```

## B. Call assistant only after validation

```java
public String safeAsk(EnterpriseAssistant assistant, String question) {
    RequestPolicy.validate(question);
    return assistant.ask(question);
}
```

# 6) Better RAG with vector store

For real enterprise RAG, replace the simple keyword retriever with:

- **Embedding model**
- **In-memory or persistent vector store**
- **Metadata filters**
- **Source whitelist**

Example concept:

```java
// Pseudocode-ish structure
EmbeddingStore<TextSegment> embeddingStore = ...
EmbeddingModel embeddingModel = ...
ContentRetriever retriever = EmbeddingStoreContentRetriever.builder()
        .embeddingStore(embeddingStore)
        .embeddingModel(embeddingModel)
        .maxResults(5)
        .minScore(0.7)
        .build();
```

Then only ingest documents from:

- SharePoint
- Confluence
- internal file shares
- internal databases
- approved intranet URLs

And **never ingest**:

- public websites
- unknown URLs
- authenticated remote sites unless your app itself has explicit approved access and policy controls

# 7) Recommended guardrail strategy

To truly enforce “enterprise-only” access, use all of these:

## Hard controls
- No web-search tool
- No browser tool
- No HTTP fetch tool
- No arbitrary URL tool
- No authenticated connector unless explicitly approved

## Data controls
- Only ingest from approved sources
- Store source metadata
- Filter by source prefix/domain
- Use allowlists

## Prompt controls
- System prompt says enterprise-only
- Refuse web requests
- Refuse unsupported sources

## Runtime controls
- Validate user input
- Validate retrieved sources
- Validate output
- Log all retrievals
