## 1) What “ACP-compatible” usually means

If by **ACP** you mean an agent that can be called through a standard protocol layer, the usual pattern is:

- define a clear **input/output contract**
- expose the agent as an **HTTP endpoint**
- optionally support **tool calling**
- keep the agent stateless or session-aware via a conversation ID

In practice, your “ACP-compatible” agent can be a service that accepts something like:

```json
{
  "conversationId": "abc-123",
  "message": "What is the weather in Paris?"
}
```

and returns:

```json
{
  "conversationId": "abc-123",
  "answer": "..."
}
```

## 4) Define the agent interface

```java
import dev.langchain4j.service.SystemMessage;
import dev.langchain4j.service.UserMessage;
import dev.langchain4j.service.MemoryId;
import dev.langchain4j.service.UserName;

public interface SupportAgent {

    @SystemMessage("""
        You are a helpful assistant.
        Answer briefly and clearly.
        If you do not know, say so.
    """)
    String chat(@MemoryId String conversationId,
                @UserName String userName,
                @UserMessage String message);
}
```

## 5) Create the model and agent

### OpenAI version

```java
import dev.langchain4j.model.chat.ChatLanguageModel;
import dev.langchain4j.model.openai.OpenAiChatModel;
import dev.langchain4j.service.AiServices;
import dev.langchain4j.memory.chat.MessageWindowChatMemory;
import dev.langchain4j.memory.chat.ChatMemory;
import dev.langchain4j.store.memory.chat.InMemoryChatMemoryStore;

public class AgentFactory {

    public static SupportAgent createOpenAiAgent() {
        ChatLanguageModel model = OpenAiChatModel.builder()
                .apiKey(System.getenv("OPENAI_API_KEY"))
                .modelName("gpt-4o-mini")
                .build();

        return AiServices.builder(SupportAgent.class)
                .chatLanguageModel(model)
                .chatMemoryProvider(memoryId ->
                        MessageWindowChatMemory.builder()
                                .id(memoryId)
                                .maxMessages(20)
                                .chatMemoryStore(new InMemoryChatMemoryStore())
                                .build())
                .build();
    }
}
```

## 6) Expose it as an ACP-style REST endpoint

```java
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/acp")
public class AgentController {

    private final SupportAgent agent;

    public AgentController() {
        // Choose one:
        this.agent = AgentFactory.createOpenAiAgent();
        // this.agent = AgentFactory.createClaudeAgent();
    }

    @PostMapping("/chat")
    public ChatResponse chat(@RequestBody ChatRequest request) {
        String answer = agent.chat(
                request.conversationId(),
                request.userName(),
                request.message()
        );

        return new ChatResponse(request.conversationId(), answer);
    }
}
```

## 8) Adding tools/functions

If your ACP agent needs to call external systems, define tools.

```java
import dev.langchain4j.agent.tool.Tool;

public class WeatherTools {

    @Tool("Get current weather for a city")
    public String getWeather(String city) {
        return "It is sunny in " + city + " with 24°C.";
    }
}
```

Then register the tool:

```java
return AiServices.builder(SupportAgent.class)
        .chatLanguageModel(model)
        .tools(new WeatherTools())
        .chatMemoryProvider(memoryId ->
                MessageWindowChatMemory.builder()
                        .id(memoryId)
                        .maxMessages(20)
                        .chatMemoryStore(new InMemoryChatMemoryStore())
                        .build())
        .build();
```

## 10) Minimal production tips

- Use a persistent chat memory store instead of in-memory if you need sessions across restarts
- Add authentication to the endpoint
- Validate input
- Set model timeouts and retry policies
- Log conversation IDs, not raw sensitive content
- Use structured output if the ACP protocol expects strict JSON

## 5.1 Load documents

You can load from files, classpath, DB, or web pages. Here’s a simple in-memory example:

```java
import dev.langchain4j.data.document.Document;
import dev.langchain4j.data.document.Metadata;

import java.util.List;

public class ShopDocuments {

    public static List<Document> load() {
        return List.of(
            Document.from("""
                Return Policy:
                - Items can be returned within 30 days of delivery.
                - Items must be unused and in original packaging.
                - Final sale items are not returnable.
                """, Metadata.metadata("source", "return-policy")),

            Document.from("""
                Shipping Policy:
                - Standard shipping takes 3-5 business days.
                - Express shipping takes 1-2 business days.
                - Orders placed after 5 PM ship next business day.
                """, Metadata.metadata("source", "shipping-policy")),

            Document.from("""
                Warranty Policy:
                - Electronics include a 1-year limited warranty.
                - Warranty covers manufacturing defects only.
                - Accidental damage is not covered.
                """, Metadata.metadata("source", "warranty-policy"))
        );
    }
}
```

## 5.2 Create embeddings and vector store

Example using an in-memory vector store.

```java
import dev.langchain4j.model.embedding.EmbeddingModel;
import dev.langchain4j.model.openai.OpenAiEmbeddingModel;
import dev.langchain4j.store.embedding.EmbeddingStore;
import dev.langchain4j.store.embedding.inmemory.InMemoryEmbeddingStore;

public class RagFactory {

    public static EmbeddingModel embeddingModel() {
        return OpenAiEmbeddingModel.builder()
                .apiKey(System.getenv("OPENAI_API_KEY"))
                .modelName("text-embedding-3-small")
                .build();
    }

    public static EmbeddingStore store() {
        return new InMemoryEmbeddingStore();
    }
}
```

If using Claude, note that Claude itself is the chat model; embeddings still typically come from OpenAI or another embedding provider, since Claude is not usually used for embeddings in this setup.

## 5.3 Index documents

```java
import dev.langchain4j.data.segment.TextSegment;
import dev.langchain4j.model.embedding.EmbeddingModel;
import dev.langchain4j.store.embedding.EmbeddingStore;
import dev.langchain4j.store.embedding.EmbeddingStoreIngestor;
import dev.langchain4j.data.document.splitter.DocumentSplitters;

import java.util.List;

public class RagIndexer {

    public static void index(EmbeddingModel embeddingModel, EmbeddingStore store) {
        List<dev.langchain4j.data.document.Document> docs = ShopDocuments.load();

        EmbeddingStoreIngestor ingestor = EmbeddingStoreIngestor.builder()
                .embeddingModel(embeddingModel)
                .embeddingStore(store)
                .documentSplitter(DocumentSplitters.recursive(300, 30))
                .build();

        ingestor.ingest(docs);
    }
}
```

## 5.4 Create retriever and content retriever

```java
import dev.langchain4j.model.embedding.EmbeddingModel;
import dev.langchain4j.rag.content.retriever.EmbeddingStoreContentRetriever;
import dev.langchain4j.store.embedding.EmbeddingStore;

public class RetrieverFactory {

    public static EmbeddingStoreContentRetriever create(EmbeddingModel embeddingModel, EmbeddingStore store) {
        return EmbeddingStoreContentRetriever.builder()
                .embeddingModel(embeddingModel)
                .embeddingStore(store)
                .maxResults(3)
                .minScore(0.6)
                .build();
    }
}
```

```java
import org.springframework.web.bind.annotation.*;

public class AgentController {

    private final ShopAgent agent;

    public AgentController() {
        var embeddingModel = RagFactory.embeddingModel();
```

# 10) Notes and best practices

## Tool calling
Use tools for:
- order status
- inventory
- user account lookup
- shipping calculation
- refund eligibility checks

## RAG
Use RAG for:
- policies
- FAQs
- manuals
- product descriptions
- internal docs

## Production improvements
- use a persistent vector store like PostgreSQL + pgvector, Pinecone, Weaviate, or Elasticsearch
- use a persistent chat memory store
- add auth and rate limiting
- add citations in answers
- log retrieval results for debugging

# 9) RAG indexer

## `rag/RagIndexer.java`

```java
package com.example.shopagent.rag;

import dev.langchain4j.data.document.Document;
import dev.langchain4j.data.document.splitter.DocumentSplitters;
import dev.langchain4j.model.embedding.EmbeddingModel;
import dev.langchain4j.store.embedding.EmbeddingStore;
import dev.langchain4j.store.embedding.EmbeddingStoreIngestor;
import org.springframework.stereotype.Component;

import jakarta.annotation.PostConstruct;
import java.util.List;

@Component
public class RagIndexer {

    private final EmbeddingModel embeddingModel;
    private final EmbeddingStore embeddingStore;

    public RagIndexer(EmbeddingModel embeddingModel, EmbeddingStore embeddingStore) {
        this.embeddingModel = embeddingModel;
        this.embeddingStore = embeddingStore;
    }

    @PostConstruct
    public void indexDocuments() {
        List<Document> documents = ShopDocuments.load();

        EmbeddingStoreIngestor ingestor = EmbeddingStoreIngestor.builder()
                .embeddingModel(embeddingModel)
                .embeddingStore(embeddingStore)
                .documentSplitter(DocumentSplitters.recursive(300, 30))
                .build();

        ingestor.ingest(documents);
    }
}
```

```java
package com.example.shopagent.agent;

import com.example.shopagent.tools.ShopTools;
import dev.langchain4j.memory.chat.ChatMemory;
import dev.langchain4j.memory.chat.MessageWindowChatMemory;
import dev.langchain4j.model.chat.ChatLanguageModel;
import dev.langchain4j.model.openai.OpenAiChatModel;
import dev.langchain4j.rag.content.retriever.ContentRetriever;
import dev.langchain4j.service.AiServices;
import dev.langchain4j.store.memory.chat.InMemoryChatMemoryStore;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class AgentFactory {

    @Bean
    public ChatLanguageModel chatLanguageModel(@Value("${app.openai.chat-model:gpt-4o-mini}") String chatModelName) {
        return OpenAiChatModel.builder()
                .apiKey(System.getenv("OPENAI_API_KEY"))
                .modelName(chatModelName)
                .build();
    }

    @Bean
    public ShopAgent shopAgent(ChatLanguageModel chatLanguageModel,
                               ContentRetriever contentRetriever) {
        return AiServices.builder(ShopAgent.class)
                .chatLanguageModel(chatLanguageModel)
                .tools(new ShopTools())
                .contentRetriever(contentRetriever)
                .chatMemoryProvider(memoryId ->
                        MessageWindowChatMemory.builder()
                                .id(memoryId)
                                .maxMessages(20)
                                .chatMemoryStore(new InMemoryChatMemoryStore())
                                .build())
                .build();
    }
}
```

# 14) How it works

## RAG
When the user asks policy-related questions, the retriever finds relevant chunks from the embedded documents, and langchain4j passes them to the model.

Example:
- “What is your return policy?”
- “How long does shipping take?”
- “Is accidental damage covered by warranty?”

## Tool calling
When the user asks something like:
- “What is the status of order 12345?”
- “Is SKU-RED-001 returnable?”

the model can call the corresponding Java tools.
