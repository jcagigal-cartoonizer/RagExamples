# 6) Guardrail service

This blocks:
- internet/web search requests
- external URLs
- authenticated remote access requests

## `RequestGuardrailService.java`

```java
package com.example.enterprise.guardrail;

import org.springframework.stereotype.Service;

import java.util.Locale;

@Service
public class RequestGuardrailService {

    public void validateUserQuestion(String question) {
        if (question == null || question.isBlank()) {
            throw new IllegalArgumentException("Question cannot be empty.");
        }

        String q = question.toLowerCase(Locale.ROOT);

        if (containsUrl(q)) {
            throw new IllegalArgumentException("External URLs are not allowed. Use approved enterprise resources only.");
        }

        if (q.contains("internet") || q.contains("web search") || q.contains("search the web")
                || q.contains("browse") || q.contains("google") || q.contains("bing")) {
            throw new IllegalArgumentException("Internet/web access is not allowed. Use approved enterprise resources only.");
        }

        if (q.contains("login") || q.contains("sign in") || q.contains("authenticated")
                || q.contains("credentials") || q.contains("password protected")) {
            throw new IllegalArgumentException("Access to authenticated remote sites is not allowed.");
        }
    }

    private boolean containsUrl(String text) {
        return text.contains("http://") || text.contains("https://") || text.contains("www.");
    }
}
```

# 7) LangChain4j configuration

This config creates:

- OpenAI chat model
- OpenAI embedding model
- In-memory vector store

## `LangChainConfig.java`

```java
package com.example.enterprise.config;

import com.example.enterprise.rag.EnterpriseAssistant;
import com.example.enterprise.rag.EnterpriseRagService;
import dev.langchain4j.data.segment.TextSegment;
import dev.langchain4j.model.chat.ChatLanguageModel;
import dev.langchain4j.model.embedding.EmbeddingModel;
import dev.langchain4j.model.openai.OpenAiChatModel;
import dev.langchain4j.model.openai.OpenAiEmbeddingModel;
import dev.langchain4j.rag.content.retriever.ContentRetriever;
import dev.langchain4j.rag.content.retriever.EmbeddingStoreContentRetriever;
import dev.langchain4j.store.embedding.EmbeddingStore;
import dev.langchain4j.store.embedding.inmemory.InMemoryEmbeddingStore;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import java.util.Set;

@Configuration
public class LangChainConfig {

    @Bean
    public ChatLanguageModel chatLanguageModel(
            @Value("${openai.api-key}") String apiKey,
            @Value("${openai.model}") String modelName
    ) {
        return OpenAiChatModel.builder()
                .apiKey(apiKey)
                .modelName(modelName)
                .temperature(0.0)
                .build();
    }

    @Bean
    public EmbeddingModel embeddingModel(@Value("${openai.api-key}") String apiKey) {
        return OpenAiEmbeddingModel.builder()
                .apiKey(apiKey)
                .modelName("text-embedding-3-small")
                .build();
    }

    @Bean
    public EmbeddingStore<TextSegment> embeddingStore() {
        return new InMemoryEmbeddingStore<>();
    }

    @Bean
    public ContentRetriever contentRetriever(
            EmbeddingStore<TextSegment> embeddingStore,
            EmbeddingModel embeddingModel
    ) {
        return EmbeddingStoreContentRetriever.builder()
                .embeddingStore(embeddingStore)
                .embeddingModel(embeddingModel)
                .maxResults(5)
                .minScore(0.65)
                .build();
    }

    @Bean
    public EnterpriseAssistant enterpriseAssistant(EnterpriseRagService ragService) {
        return ragService;
    }
}
```

# 9) RAG service

This service:
- retrieves only from approved enterprise docs
- applies metadata allowlist
- uses a strict system prompt
- refuses if context is insufficient

## `EnterpriseRagService.java`

```java
package com.example.enterprise.rag;

import dev.langchain4j.data.message.UserMessage;
import dev.langchain4j.data.segment.TextSegment;
import dev.langchain4j.model.chat.ChatLanguageModel;
import dev.langchain4j.rag.content.Content;
import dev.langchain4j.rag.content.retriever.ContentRetriever;
import org.springframework.stereotype.Service;

import java.util.List;
import java.util.Locale;
import java.util.Map;
import java.util.Set;
import java.util.stream.Collectors;

@Service
public class EnterpriseRagService implements EnterpriseAssistant {

    private final ChatLanguageModel chatLanguageModel;
    private final ContentRetriever contentRetriever;

    // Metadata allowlist
    private final Set<String> allowedSourcePrefixes = Set.of(
            "file://enterprise/",
            "https://intranet.company.local/",
            "https://docs.company.local/"
    );

    public EnterpriseRagService(ChatLanguageModel chatLanguageModel,
                                ContentRetriever contentRetriever) {
        this.chatLanguageModel = chatLanguageModel;
        this.contentRetriever = contentRetriever;
    }

    @Override
    public String answer(String question) {
        List<Content> retrieved = contentRetriever.retrieve(UserMessage.from(question));

        List<Content> allowed = retrieved.stream()
                .filter(this::isAllowedContent)
                .toList();

        String context = allowed.stream()
                .map(c -> {
                    String source = String.valueOf(c.metadata().get("source"));
                    String text = c.textSegment().text();
                    return "[SOURCE: " + source + "]\n" + text;
                })
                .collect(Collectors.joining("\n\n"));

        String systemPrompt = """
                You are an enterprise-only assistant.

                Rules:
                - Answer ONLY from the provided context.
                - Do NOT use the Internet.
                - Do NOT browse websites.
                - Do NOT access remote sites.
                - Do NOT access authenticated resources.
                - Do NOT invent facts.
                - If the answer is not in the context, say:
                  "I don't have enough approved enterprise information to answer that."
                """;

        String userPrompt = """
                Question:
                %s

                Approved enterprise context:
                %s
                """.formatted(question, context.isBlank() ? "(no relevant approved context found)" : context);

        String response = chatLanguageModel.generate(
                List.of(
                        dev.langchain4j.data.message.SystemMessage.from(systemPrompt),
                        UserMessage.from(userPrompt)
                )
        ).content().text();

        return response;
    }

    private boolean isAllowedContent(Content content) {
        Object sourceObj = content.metadata().get("source");
        if (sourceObj == null) {
            return false;
        }

        String source = sourceObj.toString();
        return allowedSourcePrefixes.stream().anyMatch(source::startsWith);
    }
}
```

# 10) Document ingestion

This loads local enterprise docs into the vector store with metadata.

## `EnterpriseDocumentIngestor.java`

```java
package com.example.enterprise.rag;

import dev.langchain4j.data.document.Document;
import dev.langchain4j.data.document.loader.FileSystemDocumentLoader;
import dev.langchain4j.data.document.parser.TextDocumentParser;
import dev.langchain4j.data.segment.TextSegment;
import dev.langchain4j.model.embedding.EmbeddingModel;
import dev.langchain4j.store.embedding.EmbeddingStore;
import dev.langchain4j.store.embedding.EmbeddingStoreIngestor;
import org.springframework.boot.CommandLineRunner;
import org.springframework.core.io.ClassPathResource;
import org.springframework.stereotype.Component;

import java.io.File;
import java.util.List;
import java.util.Map;

@Component
public class EnterpriseDocumentIngestor implements CommandLineRunner {

    private final EmbeddingStore<TextSegment> embeddingStore;
    private final EmbeddingModel embeddingModel;

    public EnterpriseDocumentIngestor(EmbeddingStore<TextSegment> embeddingStore,
                                     EmbeddingModel embeddingModel) {
        this.embeddingStore = embeddingStore;
        this.embeddingModel = embeddingModel;
    }

    @Override
    public void run(String... args) throws Exception {
        List<EnterpriseDoc> docs = List.of(
                new EnterpriseDoc("hr-policy.txt", "file://enterprise/hr-policy.txt"),
                new EnterpriseDoc("it-policy.txt", "file://enterprise/it-policy.txt"),
                new EnterpriseDoc("finance-policy.txt", "file://enterprise/finance-policy.txt")
        );

        EmbeddingStoreIngestor ingestor = EmbeddingStoreIngestor.builder()
                .embeddingStore(embeddingStore)
                .embeddingModel(embeddingModel)
                .build();

        for (EnterpriseDoc doc : docs) {
            File file = new ClassPathResource("docs/" + doc.fileName()).getFile();
            Document document = FileSystemDocumentLoader.loadDocument(file.toPath(), new TextDocumentParser());

            // Add metadata allowlist source
            document.metadata().put("source", doc.source());

            ingestor.ingest(document);
        }
    }

    private record EnterpriseDoc(String fileName, String source) {}
}
```

# 11) REST controller

## `ChatController.java`

```java
package com.example.enterprise.controller;

import com.example.enterprise.guardrail.RequestGuardrailService;
import com.example.enterprise.model.ChatRequest;
import com.example.enterprise.rag.EnterpriseAssistant;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.Map;

@RestController
@RequestMapping("/api/chat")
public class ChatController {

    private final EnterpriseAssistant assistant;
    private final RequestGuardrailService guardrailService;

    public ChatController(EnterpriseAssistant assistant,
                          RequestGuardrailService guardrailService) {
        this.assistant = assistant;
        this.guardrailService = guardrailService;
    }

    @PostMapping
    public ResponseEntity<?> chat(@RequestBody ChatRequest request) {
        try {
            guardrailService.validateUserQuestion(request.getQuestion());
            String answer = assistant.answer(request.getQuestion());
            return ResponseEntity.ok(Map.of("answer", answer));
        } catch (IllegalArgumentException ex) {
            return ResponseEntity.badRequest().body(Map.of("error", ex.getMessage()));
        } catch (Exception ex) {
            return ResponseEntity.internalServerError().body(Map.of("error", "Unexpected error"));
        }
    }
}
```

# 15) Notes on the metadata allowlist

The allowlist is enforced in two places:

1. **At ingestion time**
   - only approved docs are loaded
   - each doc gets a `source` metadata field

2. **At retrieval/answer time**
   - retrieved content is filtered by allowed source prefixes

This is important because prompt instructions alone are not enough.

# 16) Production hardening recommendations

If you want this to be truly enterprise-grade, add:

- **Authentication/authorization** on the API
- **Audit logging** of every question and retrieved source
- **PII redaction**
- **Document-level ACLs**
- **Tenant isolation**
- **Vector store persistence** instead of in-memory
- **Source provenance tracking**
- **Output citation requirement**
- **Fallback refusal when no context is found**

# 17) One important improvement

For stronger guardrails, you should also require the model to return **citations** and reject answers without them.

Example system rule:

```text
Every factual statement must be supported by a cited source from the approved context.
If no citation is available, refuse to answer.
```
