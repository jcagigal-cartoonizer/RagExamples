Below is a `Fragment` wrapper for your composable payment screen, named exactly `ifac.td.taxi.ui.screen.PaymentNavigationFragment`, using `viewModels()` for the ViewModel and only Android + Jetpack Compose APIs.

It assumes:

- you already have `PaymentComposeViewModel`
- you already have `PaymentScreen(...)`
- your `PaymentComposeViewModel` exposes:
  - `uiState: StateFlow<...>`
  - `uiEffect: Flow<...>`
  - `onEvent(...)`

If your VM constructor needs a factory, use the `by viewModels { ... }` variant shown below.

# Important note about `viewModels()`

You asked to use `viewModels()` instead of Compose `viewModel()`.

That means this import is the correct one:

```kotlin
import androidx.fragment.app.viewModels
```

If your `PaymentComposeViewModel` is created with DI and not a default constructor, you need a factory. Example:

```kotlin
private val viewModel: PaymentComposeViewModel by viewModels {
    PaymentComposeViewModelFactory(...)
}
```

If you use Hilt, it would be:

```kotlin
private val viewModel: PaymentComposeViewModel by viewModels()
```

with `@AndroidEntryPoint` on the fragment.

# Minimal version if you want no extra composable wrapper

```kotlin
package ifac.td.taxi.ui.screen

import android.os.Bundle
import android.view.View
import androidx.activity.compose.BackHandler
import androidx.compose.material3.MaterialTheme
import androidx.compose.material3.Surface
import androidx.compose.ui.Modifier
import androidx.compose.ui.platform.ComposeView
import androidx.compose.ui.platform.ViewCompositionStrategy
import androidx.fragment.app.Fragment
import androidx.fragment.app.viewModels
import androidx.navigation.fragment.findNavController
import ifac.td.taxi.compose.viewmodel.PaymentComposeViewModel

class PaymentNavigationFragment : Fragment() {

    private val viewModel: PaymentComposeViewModel by viewModels()

    override fun onCreateView(
        inflater: android.view.LayoutInflater,
        container: android.view.ViewGroup?,
        savedInstanceState: Bundle?
    ): View = ComposeView(requireContext()).apply {
        setViewCompositionStrategy(ViewCompositionStrategy.DisposeOnViewTreeLifecycleDestroyed)
        setContent {
            MaterialTheme {
                Surface {
                    PaymentScreen(
                        navController = findNavController(),
                        viewModel = viewModel,
                        onSendAppPaymentAuthRequest = { },
                        onBackToDispatched = { findNavController().popBackStack() },
                        onShowToast = { }
                    )
                    BackHandler { findNavController().popBackStack() }
                }
            }
        }
    }
}
```
