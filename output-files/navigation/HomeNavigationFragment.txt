Below is a plain Android `View` factory function that creates a `ComposeView` and hosts your `HomeScreen` composable inside `setContent`.

I’m using only Android + Jetpack Compose / Navigation APIs, and I’m taking the constructor parameters exactly from the composable signature:

- `navController`
- `viewModel`
- `sharedVm`
- `onShowToast`
- `onBeep`
- `onKeepScreenOn`

---

## 1) Plain Android `View` factory with `ComposeView`

```kotlin
package ifac.td.taxi.ui.screen

import android.content.Context
import android.view.View
import androidx.compose.ui.platform.ComposeView
import androidx.compose.ui.platform.ViewCompositionStrategy
import androidx.navigation.NavController
import ifac.td.taxi.compose.viewmodel.HomeComposeViewModel
import ifac.td.taxi.compose.viewmodel.MainActivityComposeStateHolder

fun createHomeScreenView(
    context: Context,
    navController: NavController,
    viewModel: HomeComposeViewModel,
    sharedVm: MainActivityComposeStateHolder,
    onShowToast: (Int) -> Unit,
    onBeep: (Int) -> Unit,
    onKeepScreenOn: (Boolean) -> Unit,
): View {
    return ComposeView(context).apply {
        // Recommended so the composition is disposed with the host view lifecycle
        setViewCompositionStrategy(
            ViewCompositionStrategy.DisposeOnViewTreeLifecycleDestroyed
        )

        setContent {
            HomeScreen(
                navController = navController,
                viewModel = viewModel,
                sharedVm = sharedVm,
                onShowToast = onShowToast,
                onBeep = onBeep,
                onKeepScreenOn = onKeepScreenOn
            )
        }
    }
}
```

## 2) Example usage in a Fragment-based Android Views navigation setup

If you are using the traditional Android Views / Fragment navigation approach, you can return this view from a Fragment’s `onCreateView()`.

### Example Fragment

```kotlin
package ifac.td.taxi.ui.screen

import android.os.Bundle
import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import android.widget.Toast
import androidx.fragment.app.Fragment
import androidx.navigation.fragment.findNavController
import androidx.fragment.app.activityViewModels
import ifac.td.taxi.compose.viewmodel.HomeComposeViewModel
import ifac.td.taxi.compose.viewmodel.MainActivityComposeStateHolder

class HomeFragment : Fragment() {

    private val viewModel: HomeComposeViewModel by activityViewModels()
    private val sharedVm: MainActivityComposeStateHolder by activityViewModels()

    override fun onCreateView(
        inflater: LayoutInflater,
        container: ViewGroup?,
        savedInstanceState: Bundle?
    ): View {
        return createHomeScreenView(
            context = requireContext(),
            navController = findNavController(),
            viewModel = viewModel,
            sharedVm = sharedVm,
            onShowToast = { resId ->
                Toast.makeText(requireContext(), getString(resId), Toast.LENGTH_SHORT).show()
            },
            onBeep = { tone ->
                // Example placeholder:
                // call your beep logic here
            },
            onKeepScreenOn = { keepOn ->
                requireActivity().window.addFlags(
                    android.view.WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON
                )
                if (!keepOn) {
                    requireActivity().window.clearFlags(
                        android.view.WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON
                    )
                }
            }
        )
    }
}
```

## 3) Example usage with a `NavHostFragment` destination in XML navigation

If you already have a standard Views navigation graph, your `HomeFragment` can be declared as a destination, and that fragment simply returns the `ComposeView`-backed view as shown above.

### Example navigation graph snippet

```xml
<fragment
    android:id="@+id/homeFragment"
    android:name="ifac.td.taxi.ui.screen.HomeFragment"
    android:label="Home" />
```

Then navigate to it as usual from another fragment:

```kotlin
findNavController().navigate(R.id.homeFragment)
```

## 4) If you want a reusable `View` factory without Fragment code

You can also use it directly from an Activity or any view container:

```kotlin
val homeView = createHomeScreenView(
    context = this,
    navController = navController,
    viewModel = homeComposeViewModel,
    sharedVm = sharedVm,
    onShowToast = { resId -> /* show toast */ },
    onBeep = { tone -> /* beep */ },
    onKeepScreenOn = { keepOn -> /* keep screen on */ }
)
```

Then add it to a parent layout:

```kotlin
parentLayout.addView(homeView)
```

---

## Notes

- `ComposeView` is the correct bridge for embedding Compose inside the classic Android View system.
- `ViewCompositionStrategy.DisposeOnViewTreeLifecycleDestroyed` is recommended to avoid leaks.
- The callback parameters are passed directly from the composable signature, exactly as requested.
