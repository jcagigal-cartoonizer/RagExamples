Below is a Compose-first replacement for the `AboutFragment` + `AboutViewModel`, while preserving the same navigation behavior and the same fragment logic branches.

I’m giving you:

1. `AboutScreen` composable
2. `AboutViewModel` rewritten as `UiState + UiEvent + SharedFlow<AboutUiEffect>`
3. `AboutMainActivityViewModel` Compose bridge
4. `AboutButtonsState` reducer that mirrors the fragment logic branch-by-branch
5. `AboutUiState`, `AboutUiEvent`, `AboutUiEffect`, `AboutDialogState`, `AboutButtonVisualState`
6. A small dialog-handling pattern only for the browser warning case, since the original fragment used a toast-like warning flow and not a custom dialog

## 2) Exact `AboutButtonsState` reducer

This mirrors the fragment button logic one-by-one:

- `btnAccept.setAction { iMainActivity.navigateBack() }`
- `logotaxitronic` click counter increments
- at 5 clicks, `W2CLocation.setTrackingState(...)` and reset counter

```kotlin
package ifac.td.taxi.ui.screen.about

import com.interfacom.sdk.taximeter.bravocomm.W2CLocation
import com.interfacom.sdk.taximeter.bravocomm.location.AlfaLocation

object AboutButtonsReducer {

    fun reduce(
        current: AboutButtonsState,
        event: AboutUiEvent
    ): AboutButtonsState {
        return when (event) {
            AboutUiEvent.OnAcceptClicked -> {
                current
            }

            AboutUiEvent.OnLogoClicked -> {
                val newCounter = current.logoTapCounter + 1
                if (newCounter == 5) {
                    W2CLocation.setTrackingState(
                        AlfaLocation.ESTADO_SEGUIMIENTO_ALARMA,
                        "1"
                    )
                    current.copy(logoTapCounter = 0)
                } else {
                    current.copy(logoTapCounter = newCounter)
                }
            }

            else -> current
        }
    }
}
```

## 3) Compose-friendly `AboutViewModel`

This replaces the fragment’s `deviceFlow` and `warningFlow` with:

- `StateFlow<AboutUiState>`
- `SharedFlow<AboutUiEffect>`

It keeps the same behavior:
- `checkSavedDevice()` loads local bluetooth
- if privacy URL cannot open, emit warning effect
- device info is built exactly like the fragment

```kotlin
package ifac.td.taxi.ui.screen.about

import android.app.Application
import android.content.ActivityNotFoundException
import android.content.Intent
import android.net.Uri
import androidx.lifecycle.AndroidViewModel
import androidx.lifecycle.viewModelScope
import com.interfacom.sdk.taximeter.taximeter.Taximeter
import ifac.td.taxi.R
import ifac.td.taxi.domain.usecase.BluetoothLocalUseCase
import ifac.td.taxi.framework.sdk.model.BluetoothInfo
import ifac.td.taxi.framework.util.ApkUtils
import ifac.td.taxi.framework.util.Logs
import kotlinx.coroutines.flow.MutableSharedFlow
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.asSharedFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch

class AboutViewModel(
    application: Application,
    private val bluetoothLocalUseCase: BluetoothLocalUseCase,
) : AndroidViewModel(application) {

    private val TAG = "AboutViewModel"

    private val _uiState = MutableStateFlow(AboutUiState())
    val uiState = _uiState.asStateFlow()

    private val _uiEffect = MutableSharedFlow<AboutUiEffect>()
    val uiEffect = _uiEffect.asSharedFlow()

    fun onEvent(event: AboutUiEvent) {
        _uiState.update { current ->
            current.copy(
                buttonsState = AboutButtonsReducer.reduce(current.buttonsState, event)
            )
        }

        when (event) {
            AboutUiEvent.OnScreenStarted -> checkSavedDevice()
            AboutUiEvent.OnAcceptClicked -> emitEffect(AboutUiEffect.NavigateBack)
            AboutUiEvent.OnPrivacyClicked -> clickPrivacy()
            AboutUiEvent.OnLogoClicked -> Unit
            AboutUiEvent.OnDialogDismissed -> {
                _uiState.update { it.copy(dialogState = AboutDialogState.Hidden) }
            }
        }
    }

    private fun emitEffect(effect: AboutUiEffect) {
        viewModelScope.launch { _uiEffect.emit(effect) }
    }

    fun clickPrivacy() {
        val privacyPolicyUrl = "https://www.taxitronic.com/en/privacy-policy-smart-td/"
        val intent = Intent(Intent.ACTION_VIEW, Uri.parse(privacyPolicyUrl)).apply {
            flags = Intent.FLAG_ACTIVITY_NEW_TASK
        }

        try {
            getApplication<Application>().startActivity(intent)
            emitEffect(AboutUiEffect.OpenPrivacyPolicy)
        } catch (e: ActivityNotFoundException) {
            viewModelScope.launch {
                _uiState.update {
                    it.copy(dialogState = AboutDialogState.Warning(R.string.warning_not_browser))
                }
                _uiEffect.emit(AboutUiEffect.ShowBrowserWarningToast)
            }
            Logs.d(TAG, "clickPrivacy: No hay navegador disponible para abrir este enlace")
        }
    }

    fun checkSavedDevice() {
        viewModelScope.launch {
            val bluetooth = bluetoothLocalUseCase.getLocalBluetooth()
            val isDeviceAvailable = bluetooth != null

            val deviceInfo = if (isDeviceAvailable && bluetooth != null) {
                buildDeviceInfo(bluetooth)
            } else {
                ""
            }

            _uiState.update {
                it.copy(
                    bluetoothInfoText = deviceInfo,
                    isBluetoothInfoVisible = isDeviceAvailable && bluetooth != null
                )
            }
        }
    }

    private fun buildDeviceInfo(bluetoothInfo: BluetoothInfo): String {
        val taximeter = Taximeter.getInstance()
        return buildString {
            appendLine("${bluetoothInfo.name} [${bluetoothInfo.btPIN}]")

            val firmware = taximeter.taximeterVersionFirmware
            val hardware = taximeter.taximeterVersionHardware
            if (firmware.isNotEmpty() && hardware.isNotEmpty()) {
                appendLine("$firmware - $hardware")
            }

            val answerK62 = taximeter.answerK62
            if (answerK62.isNotEmpty()) {
                appendLine(answerK62)
            }
        }
    }

    fun buildAppInfoText(): String {
        val context = getApplication<Application>()
        val name = ApkUtils.getAppNameVersionDate(true, false, false, context)
        val version = ApkUtils.getAppNameVersionDate(false, true, false, context)
        val date = ApkUtils.getAppNameVersionDate(false, false, true, context)
        return context.getString(R.string.app_info_format, name, version, date)
    }
}
```

## 6) Exact XML behavior mapping notes

### Fragment behavior preserved
- `iMainActivity.showHeader(false)`  
  -> do this from the host activity / screen scaffold, not inside the composable itself.

- `btnAccept.setAction { iMainActivity.navigateBack() }`  
  -> `AboutUiEffect.NavigateBack`

- `tvPrivacyPolicy` underlined and clickable  
  -> Compose `Text` with underline + click handler

- `vModel.checkSavedDevice()` on setup  
  -> `OnScreenStarted` triggers `checkSavedDevice()`

- `deviceFlow.collect { ... }`  
  -> replaced by `uiState.bluetoothInfoText` + `isBluetoothInfoVisible`

- `warningFlow.collect { iMainActivity.showToast(...) }`  
  -> replaced by `AboutUiEffect.ShowBrowserWarningToast`

- `logotaxitronic` 5-click hidden action  
  -> `AboutButtonsReducer` with counter and `W2CLocation.setTrackingState(...)`
