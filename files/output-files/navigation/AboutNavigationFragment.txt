Below is a simple **Fragment destination wrapper** named:

`ifac.td.taxi.ui.screen.AboutNavigationFragment`

It keeps your existing **XML Navigation Component** setup, but hosts the **Compose `AboutScreen`** instead of the old ViewBinding-based `AboutFragment`.

It uses:

- `Fragment`
- `viewModels()` for the `AboutViewModel`
- `setContent { ... }` from Jetpack Compose
- only Android / Jetpack Compose / Jetpack Navigation / Lifecycle APIs

---

## 1) Compose-hosting Fragment

```kotlin
package ifac.td.taxi.ui.screen

import android.os.Bundle
import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import androidx.activity.compose.BackHandler
import androidx.compose.material3.MaterialTheme
import androidx.compose.runtime.Composable
import androidx.compose.runtime.collectAsState
import androidx.compose.runtime.getValue
import androidx.compose.ui.platform.ComposeView
import androidx.compose.ui.platform.ViewCompositionStrategy
import androidx.compose.ui.tooling.preview.Preview
import androidx.fragment.app.Fragment
import androidx.fragment.app.viewModels
import ifac.td.taxi.viewmodel.AboutViewModel

class AboutNavigationFragment : Fragment() {

    private val viewModel: AboutViewModel by viewModels()

    override fun onCreateView(
        inflater: LayoutInflater,
        container: ViewGroup?,
        savedInstanceState: Bundle?
    ): View {
        return ComposeView(requireContext()).apply {
            setViewCompositionStrategy(
                ViewCompositionStrategy.DisposeOnViewTreeLifecycleDestroyed
            )
            setContent {
                MaterialTheme {
                    AboutNavigationRoute(
                        viewModel = viewModel,
                        onNavigateBack = {
                            parentFragmentManager.popBackStack()
                        },
                        onOpenPrivacy = {
                            viewModel.clickPrivacy()
                        },
                        onLogoClick = {
                            viewModel.onLogoClicked()
                        },
                        onDismissDialog = {
                            viewModel.onDismissDialog()
                        }
                    )
                }
            }
        }
    }
}

@Composable
private fun AboutNavigationRoute(
    viewModel: AboutViewModel,
    onNavigateBack: () -> Unit,
    onOpenPrivacy: () -> Unit,
    onLogoClick: () -> Unit,
    onDismissDialog: () -> Unit
) {
    val uiState by viewModel.uiState.collectAsState()

    BackHandler {
        onNavigateBack()
    }

    AboutScreen(
        uiState = uiState,
        onAcceptClick = onNavigateBack,
        onPrivacyClick = onOpenPrivacy,
        onLogoClick = onLogoClick,
        onDismissDialog = onDismissDialog
    )
}
```

## 2) Update the navigation XML

Replace the destination class from:

```xml
<fragment
    android:id="@+id/aboutFragment"
    android:name="ifac.td.taxi.ui.screen.AboutFragment"
    android:label="AboutFragment"
    tools:layout="@layout/fragment_about"/>
```

to:

```xml
<fragment
    android:id="@+id/aboutFragment"
    android:name="ifac.td.taxi.ui.screen.AboutNavigationFragment"
    android:label="AboutFragment"
    tools:layout="@layout/fragment_about"/>
```

So your navigation graph can stay the same, only the fragment class changes.

## 3) ViewModel expectations

This fragment assumes your `AboutViewModel` exposes something like:

```kotlin

```

and has functions like:

```kotlin
fun clickPrivacy()
fun onLogoClicked()
fun onDismissDialog()
```

If your current `AboutViewModel` names differ, just map them inside `AboutNavigationRoute`.

---

## 4) Important note about back navigation

In your old Fragment you used:

```kotlin
iMainActivity.navigateBack()
```

In the Compose-hosting fragment above, I used:

```kotlin
parentFragmentManager.popBackStack()
```

If you want to use the **NavController** instead, that is usually better with Navigation Component. For example:

```kotlin
findNavController().navigateUp()
```

If you use that, just import:

```kotlin
import androidx.navigation.fragment.findNavController
```

and replace the `onNavigateBack` implementation with:

```kotlin
onNavigateBack = { findNavController().navigateUp() }
```

That is likely the cleanest option.
