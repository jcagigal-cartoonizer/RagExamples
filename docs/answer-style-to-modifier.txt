### Checkbox

In XML you have:
- `CheckBox`
- `CheckBoxEnabled`

Compose equivalent:

```kotlin
import androidx.compose.material3.Checkbox
import androidx.compose.material3.CheckboxDefaults
import androidx.compose.runtime.Composable
import androidx.compose.ui.graphics.Color

@Composable
fun SmartTdCheckBox(
    checked: Boolean,
    onCheckedChange: (Boolean) -> Unit,
    enabled: Boolean = true
) {
    val boxColor = if (enabled) SmartTdTheme.Colors.CheckBoxColors else SmartTdTheme.Colors.White

    Checkbox(
        checked = checked,
        onCheckedChange = onCheckedChange,
        enabled = enabled,
        colors = CheckboxDefaults.colors(
            checkedColor = boxColor,
            uncheckedColor = boxColor,
            checkmarkColor = SmartTdTheme.Colors.White
        )
    )
}
```

If you need text beside it, use `Row` + `Text`.

### Custom EditText

XML style:
- textSize medium
- white text
- white background tint
- hint grey
- custom cursor
- `flagNoFullscreen`

Compose `TextField` equivalent:

```kotlin
import androidx.compose.material3.OutlinedTextField
import androidx.compose.material3.TextFieldDefaults
import androidx.compose.runtime.Composable
import androidx.compose.ui.text.input.KeyboardOptions
import androidx.compose.ui.text.input.ImeAction

@Composable
fun SmartTdTextField(
    value: String,
    onValueChange: (String) -> Unit,
    modifier: Modifier = Modifier,
    placeholder: String? = null
) {
    OutlinedTextField(
        value = value,
        onValueChange = onValueChange,
        modifier = modifier,
        textStyle = SmartTdTextStyles.TextView,
        placeholder = {
            if (placeholder != null) {
                Text(
                    text = placeholder,
                    style = SmartTdTextStyles.TextView.copy(color = SmartTdTheme.Colors.DisabledGrey)
                )
            }
        },
        keyboardOptions = KeyboardOptions.Default.copy(
            imeAction = ImeAction.Default
        ),
        colors = TextFieldDefaults.colors(
            focusedTextColor = SmartTdTheme.Colors.White,
            unfocusedTextColor = SmartTdTheme.Colors.White,
            focusedContainerColor = SmartTdTheme.Colors.Transparent,
            unfocusedContainerColor = SmartTdTheme.Colors.Transparent,
            cursorColor = SmartTdTheme.Colors.White,
            focusedIndicatorColor = SmartTdTheme.Colors.White,
            unfocusedIndicatorColor = SmartTdTheme.Colors.White,
            focusedPlaceholderColor = SmartTdTheme.Colors.DisabledGrey,
            unfocusedPlaceholderColor = SmartTdTheme.Colors.DisabledGrey
        )
    )
}
```

Note: Compose does not directly expose `android:textCursorDrawable` like Views do; cursor color is the Compose equivalent styling.

### Floating button

XML style:
- white text
- custom background drawable

Compose version can use a `Button` or `Surface` with a custom shape/background.

```kotlin
import androidx.compose.material3.Button
import androidx.compose.material3.ButtonDefaults
import androidx.compose.runtime.Composable

@Composable
fun SmartTdFloatingButton(
    text: String,
    onClick: () -> Unit
) {
    Button(
        onClick = onClick,
        colors = ButtonDefaults.buttonColors(
            containerColor = SmartTdTheme.Colors.Transparent,
            contentColor = SmartTdTheme.Colors.White
        )
    ) {
        Text(text = text, color = SmartTdTheme.Colors.White)
    }
}
```

If your XML drawable defines a special shape, replace this with `shape = RoundedCornerShape(...)` and `modifier.background(...)`.

### Spinner

Compose equivalent is `DropdownMenu` + `ExposedDropdownMenuBox` or plain `DropdownMenu`.

```kotlin
import androidx.compose.material3.*
import androidx.compose.runtime.*
import androidx.compose.ui.Modifier

@Composable
fun SmartTdSpinner(
    items: List<String>,
    selectedItem: String,
    onItemSelected: (String) -> Unit,
    modifier: Modifier = Modifier
) {
    var expanded by remember { mutableStateOf(false) }

    ExposedDropdownMenuBox(
        expanded = expanded,
        onExpandedChange = { expanded = !expanded },
        modifier = modifier
    ) {
        OutlinedTextField(
            value = selectedItem,
            onValueChange = {},
            readOnly = true,
            textStyle = SmartTdTextStyles.TextView,
            colors = TextFieldDefaults.colors(
                focusedTextColor = SmartTdTheme.Colors.White,
                unfocusedTextColor = SmartTdTheme.Colors.White,
                focusedContainerColor = SmartTdTheme.Colors.DisabledWhite,
                unfocusedContainerColor = SmartTdTheme.Colors.DisabledWhite
            ),
            modifier = Modifier.menuAnchor()
        )

        ExposedDropdownMenu(
            expanded = expanded,
            onDismissRequest = { expanded = false }
        ) {
            items.forEach { item ->
                DropdownMenuItem(
                    text = { Text(item, color = SmartTdTheme.Colors.White) },
                    onClick = {
                        onItemSelected(item)
                        expanded = false
                    }
                )
            }
        }
    }
}
```

## 6) Notes on XML-to-Compose mapping

Some XML attributes do not have a direct 1:1 Compose equivalent:

- `android:textCursorDrawable` → Compose uses cursor color styling, not drawable cursor tint.
- `android:backgroundTint` on many widgets → Compose uses `containerColor` / `background(...)`.
- `android:fontFamily` → Compose uses `FontFamily(Font(R.font...))`.
- `shapeAppearance` → Compose uses `RoundedCornerShape`, `CutCornerShape`, etc.
- `buttonTint` / `thumbTint` / `trackTint` → Compose uses `CheckboxDefaults`, `SwitchDefaults`, `SliderDefaults`.
