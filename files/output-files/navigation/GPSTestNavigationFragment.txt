Below is a `Fragment` wrapper that uses your existing `GPSTestScreen` composable, but behaves like the old `GPSTestFragment` and can be used as a navigation destination.

It is named exactly:

`ifac.td.taxi.ui.screen.GPSTestNavigationFragment`

It uses:

- `viewModels()` for the Compose ViewModel
- only Android + Jetpack Compose / Jetpack lifecycle / Navigation references
- `ComposeView` to host `GPSTestScreen`

---

## `GPSTestNavigationFragment.kt`

```kotlin
package ifac.td.taxi.ui.screen

import android.content.Intent
import android.os.Bundle
import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import androidx.compose.ui.platform.ComposeView
import androidx.compose.ui.platform.ViewCompositionStrategy
import androidx.fragment.app.Fragment
import androidx.fragment.app.viewModels
import androidx.lifecycle.compose.collectAsStateWithLifecycle
import ifac.td.taxi.viewmodel.GPSTestComposeViewModel

class GPSTestNavigationFragment : Fragment() {

    private val viewModel: GPSTestComposeViewModel by viewModels()

    override fun onCreateView(
        inflater: LayoutInflater,
        container: ViewGroup?,
        savedInstanceState: Bundle?,
    ): View {
        return ComposeView(requireContext()).apply {
            setViewCompositionStrategy(
                ViewCompositionStrategy.DisposeOnViewTreeLifecycleDestroyed
            )
            setContent {
                GPSTestScreen(
                    viewModel = viewModel,
                    onNavigateBack = {
                        parentFragmentManager.popBackStack()
                    },
                    launchIntent = { intent: Intent ->
                        startActivity(intent)
                    }
                )
            }
        }
    }
}
```

## Notes

### 1. Back navigation
I used:

```kotlin
parentFragmentManager.popBackStack()
```

If your app uses `NavController` back stack navigation, it is better to call:

```kotlin
findNavController().popBackStack()
```

If you want that version, use this instead:

```kotlin
import androidx.navigation.fragment.findNavController
```

and inside `onNavigateBack`:

```kotlin
onNavigateBack = {
    findNavController().popBackStack()
}
```

---

### 2. Intent launching
The composable already emits `launchIntent(intent)`, so in the fragment we simply do:

```kotlin
startActivity(intent)
```

If you want to be safer, you can wrap it:

```kotlin
runCatching { startActivity(intent) }
```

---

### 3. Why this works
This fragment is just a `ComposeView` host, so it can be used in the XML navigation graph exactly like your old fragment, while the UI comes from the composable `GPSTestScreen`.
