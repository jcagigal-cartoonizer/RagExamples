## 5) Recommended small adjustment
Inside the composable, if you are using:
```kotlin
LaunchedEffect(Unit) {
    lifecycleOwner.lifecycle.repeatOnLifecycle(Lifecycle.State.STARTED) {
        viewModel.effects.collect { ... }
    }
}
```
that is fine, but in Compose it is often cleaner to collect directly with `collectLatest` in a `LaunchedEffect(viewModel)` or use `flowWithLifecycle`.
